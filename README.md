# 📚 Minha Aula

Horário de aulas e lembretes para alunos. Funciona no celular e no computador, online e offline.

## Recursos
- Horário por dia da semana, com a tela **Hoje** mostrando as aulas do dia
- Lembretes de um dia ou fixos (1 dia, 3 dias, 1 semana, 1 mês ou para sempre)
- Compartilhar o horário com colegas por código
- Backup completo dos dados
- Notificações (aula em 10 min e lembretes com hora) enquanto o app estiver aberto
- Dados salvos no próprio aparelho, sem cadastro

## Como usar
Abra o site publicado pelo GitHub Pages ou o arquivo `index.html` direto no navegador.

## Publicar no GitHub Pages
1. Envie `index.html` e `README.md` para um repositório
2. Vá em **Settings → Pages**
3. Em **Branch**, escolha `main` e a pasta `/ (root)`, depois clique em **Save**
4. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`
