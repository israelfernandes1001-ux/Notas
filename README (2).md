# 📚 Minha Aula · Escola SESI

Horário, lembretes pessoais e avisos por sala (2º A, B, C e D) com moderadores e painel do dono.

## Ligar o banco de dados (Supabase, grátis)
1. Crie uma conta em supabase.com e um projeto novo
2. Abra `supabase.sql`, troque `TROQUE-ESTE-CODIGO` pelo seu código de dono e cole tudo em **SQL Editor → Run**
3. Em **Project Settings → API**, copie a **Project URL** e a chave **anon public**
4. No `index.html`, procure `const SB={url:'',key:''}` e cole os dois valores
5. Envie para o GitHub e ative **Settings → Pages** (branch `main`, pasta `/ (root)`)

## Como o dono entra
No app, vá em **Perfil → Sou o dono**, digite o código e a aba **Painel** aparece..
